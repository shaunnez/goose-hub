# skills/acceptance-contract

Lightweight legacy acceptance-contract authoring. It runs after investigation for legacy bug/chore work and before implementation.

## Files

| File | Purpose |
| --- | --- |
| `prompt.md` | Instructions for turning issue + investigation into falsifiable ACs |
| `schema.ts` | Structured output contract |
| `skill.config.ts` | Context schema, allowlist, role, and tool bundles |
