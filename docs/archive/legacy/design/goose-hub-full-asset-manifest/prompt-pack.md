
# Master Asset Prompt Pack

Use these prompts iteratively. Do NOT generate all assets simultaneously.

---

# Global Style Rules

STYLE:
- top-down pixel art
- Phaser-compatible
- 16x16 tile logic
- cozy cyber-office
- readable at runtime
- pixel perfect
- no anti-aliasing
- dark navy palette
- cyan monitor glow
- warm amber lighting
- subtle texture only

Avoid:
- painterly shading
- blurry pixels
- excessive detail
- strong outlines
- noisy textures
- cinematic composition

All assets should feel:
clean,
playable,
runtime-readable,
and implementation-oriented.
