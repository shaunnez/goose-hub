# M17 Office tab — visual reference

PNG captures of the Office tab against the mock pipeline harness, regenerated by:

```sh
RUN_SCREENSHOTS=1 pnpm --filter @goose-hub/web exec playwright test \
  --config playwright-e2e-pipeline.config.ts office-screenshots
cp apps/web/test-results/office-screenshots/*.png docs/screenshots/m17/
```

The spec auto-skips without `RUN_SCREENSHOTS=1` so it never burdens CI — it's a documentation aid, not an assertion.

The spec lives at `apps/web/e2e/pipeline/office-screenshots.spec.ts`.

| File | Shows |
| --- | --- |
| `01-sidebar-with-office-entry.png` | Sidebar with the new "Office" nav item between Kanban and Inbox |
