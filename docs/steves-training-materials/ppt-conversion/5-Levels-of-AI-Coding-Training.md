Engineering the Dark Factory

MODULE 3

Scenarios vs. Tests
The Digital Twin Universe
Traditional tests live in the codebase. AI "teaches to the test" and games the results.
Simulated versions of external services (Okta, Jira, Slack) for autonomous agents to test against.
Solution: External behavioral specs that live outside the code so the AI cannot optimize around them.
Key Benefit: Agents can run thousands of integration tests without touching real data or services.

The $1,000 Rule: If you haven't spent $1,000 per engineer per day
on compute, your "factory" has room for improvement.

The "Better Engineer" of 2026

MODULE 6

THE HOLLOW MIDDLE
Systems Thinking
01
AI handles the bottom of the skill stack (routine tasks, boilerplate, implementation). Seniors handle the top (judgment, architecture, vision).
Identify where an architecture breaks under load. See the forest, not just the trees.
Result: The traditional junior learning path is being hollowed out. Mid-level task execution is automated.

Articulation
02
Describe a problem so clearly that a machine cannot guess wrong. Precision in specs is the new superpower.

Customer Intuition
03
Understand the "why" behind the "what." Empathy and product sense are irreplaceable.
