The Golden Rule: Folder Access & Security

Cowork can ONLY touch folders you explicitly allow.
Create a dedicated folder (e.g., ~/Cowork/) for tasks
Be specific -- give access only to the relevant folder
Cowork asks permission before accessing any folder
You confirm each time -- it cannot bypass this
Use the narrowest folder scope possible for each task
Security Model:
Your Computer
   Documents/          (locked)
   Desktop/              (locked)
   Cowork/               (unlocked)
      Project A/       (accessible)
      Project B/       (accessible)

Model Selection

Choose your model in the right-hand panel before running a task:
| Model | Best For | Token Usage |
| --- | --- | --- |
| Sonnet 4.5 | Everyday tasks, file organization, basic documents | Standard |

Current Limitations

Cowork is a Research Preview -- these will improve over time.
| Limitation | Detail |
| --- | --- |
| No cross-session memory | Doesn't remember previous sessions. Workaround: maintain files documenting work. |
| No chat sharing | Can't easily share Cowork chats with other users |
| Desktop only | Requires Claude Desktop app (not on mobile/web) |
| Session persistence | App must stay open -- closing stops the task |
| Computer resources | Tasks consume local compute power while running |
| Token consumption | Heavier tasks burn through usage allowance faster |
